## aprs-deviceid (the device identification table)

`pdn_aprs_deviceid.c` (`src/pdn_aprs_deviceid.c`, `dist/pdn_aprs_deviceid.c`) holds data from the APRS device identification database, [aprsorg/aprs-deviceid](https://github.com/aprsorg/aprs-deviceid), maintained by Heikki Hannikainen, OH7LZB, and its contributors.

- Source: `tocalls.yaml` at commit [`845e3f89d54402a9aa90e765e14c14b7e5710892`](https://github.com/aprsorg/aprs-deviceid/commit/845e3f89d54402a9aa90e765e14c14b7e5710892) (2026-09-18).
- Generated by: `tools/gen_deviceid.py` in this repository.
- Licence: [Creative Commons Attribution-ShareAlike 2.0](https://creativecommons.org/licenses/by-sa/2.0/) (CC BY-SA 2.0). In the database's own words: "you're free to use it in any of your applications, commercial, free or open source. For free. Just mention the source somewhere in the small print."
- Changes: the YAML was converted to C tables of tocall patterns, Mic-E suffixes and legacy Mic-E type codes with their vendor, model and class. Text outside ASCII is written as octal escapes of its UTF-8 bytes; it is otherwise as published. One model name in the source data contains an em dash; it is kept, escaped, as published.

This file is optional. The rest of the library (`pdn_aprs.h`, `pdn_aprs.c`) is MIT-licensed and builds and works without it; a product that leaves the file out carries no CC BY-SA data.

## Named symbols

The names of the named symbols (`PDN_APRS_SYMBOL_CAR` and so on) follow Packet.Aprs's `AprsSymbol.Named.cs` in [packet-net/packet.net](https://github.com/packet-net/packet.net), so that they match across the packet-net APRS libraries; `tools/gen_symbols.py` generates them. The symbol descriptions are those of the APRS symbol tables (APRS12c ch. 21).
